# 常用硬件排查指令整理

> 用途：把聊天记录、照片截图里经常出现的 Linux 硬件排查命令整理成可检索文档。后续把截图/文字继续发来后，可以按本文格式继续补充、归类和去重。

## 使用建议

- **先看设备是否存在**：用 `lspci`、`lsusb`、`ls /dev/*` 这类命令确认系统是否识别到硬件。
- **再看驱动是否加载**：用 `lsmod`、`lspci -k`、`dmesg` 查看内核驱动和报错。
- **最后看应用层节点/权限**：例如视频采集卡看 `/dev/video*`，串口看 `/dev/ttyUSB*` / `/dev/ttyS*`。
- **保存排查结果**：重要命令可以追加 `| tee 文件名.txt` 保存，例如：`dmesg | grep -i usb | tee usb排查.txt`。

## 可直接运行的一键检查脚本

如果你想直接在机器上跑一遍常用检查，可以使用仓库里的脚本：

```bash
./scripts/hardware_check.sh
```

也可以只检查某一类问题：

```bash
./scripts/hardware_check.sh gpu
./scripts/hardware_check.sh capture
./scripts/hardware_check.sh serial
./scripts/hardware_check.sh logs
```

**说明**：本文档是指令说明和整理表，`scripts/hardware_check.sh` 是可以直接执行的一键检查文件。脚本会尽量继续执行后续检查，即使某条命令在当前环境中没有设备、没有权限或缺少工具。

## 显卡相关

### 查看显卡型号

```bash
lspci | egrep -i 'vga|3d|display'
```

**用途**：查看机器上的显卡/显示控制器型号，适合确认是否识别到独显、核显或多显卡。

### 查看显卡使用的驱动

```bash
lspci -k | grep -A 3 -Ei 'vga|3d|display'
```

**用途**：查看显卡设备绑定的内核驱动，例如 `nvidia`、`amdgpu`、`i915`、`nouveau` 等。

### 查看 NVIDIA 显卡状态

```bash
nvidia-smi
```

**用途**：查看 NVIDIA 驱动是否正常、GPU 型号、显存占用、温度、功耗和正在使用 GPU 的进程。

### 查看图形/显示相关日志

```bash
dmesg | grep -Ei 'nvidia|amdgpu|i915|drm|gpu'
```

**用途**：排查显卡驱动加载失败、固件缺失、显示初始化失败等问题。

## 采集卡相关

### 查看 PCIe 采集卡是否识别

```bash
lspci | grep -Ei 'video|multimedia|capture|blackmagic|magewell|avermedia'
```

**用途**：查看 PCIe 采集卡是否出现在 PCI 设备列表里。

### 查看 USB 采集卡是否识别

```bash
lsusb
```

**用途**：查看 USB 采集卡是否被系统识别，能看到厂商 ID、产品 ID 和设备名称。

### 查看采集卡驱动

```bash
lspci -k | grep -A 4 -Ei 'video|multimedia|capture'
```

**用途**：查看 PCIe 采集卡是否绑定驱动，以及可用的内核模块。

### 查看采集卡是否有视频节点

```bash
ls -l /dev/video*
```

**用途**：确认系统是否生成 V4L2 视频节点。没有 `/dev/video*` 时，通常说明设备未识别、驱动未加载、设备不支持 V4L2，或权限/容器映射有问题。

### 查看视频设备和节点对应关系

```bash
v4l2-ctl --list-devices
```

**用途**：列出每个视频设备对应的 `/dev/videoX` 节点，适合多采集卡、多摄像头场景。

### 查看某个视频节点支持的格式

```bash
v4l2-ctl -d /dev/video0 --list-formats-ext
```

**用途**：查看采集卡支持的分辨率、帧率和像素格式。

## USB 转串口相关

### 查看 USB 转串口设备

```bash
lsusb
```

**用途**：查看 USB 转串口芯片是否识别，例如 CH340、CP210x、FTDI、PL2303 等。

### 查看 USB 转串口生成的节点

```bash
dmesg | grep -Ei 'ttyUSB|ttyACM|ch34|cp210|ftdi|pl2303'
```

**用途**：查看插入 USB 转串口后系统分配了哪个设备节点，例如 `/dev/ttyUSB0` 或 `/dev/ttyACM0`。

### 查看当前 USB 串口节点

```bash
ls -l /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
```

**用途**：快速列出当前存在的 USB 串口设备。

### 查看 USB 串口驱动模块

```bash
lsmod | grep -Ei 'usbserial|ch341|cp210x|ftdi_sio|pl2303'
```

**用途**：确认 USB 串口相关内核模块是否加载。

## RS-232 串口相关

### 查看原生串口节点

```bash
ls -l /dev/ttyS*
```

**用途**：查看主板或扩展卡上的传统 RS-232 串口节点，例如 `/dev/ttyS0`、`/dev/ttyS1`。

### 查看串口硬件信息

```bash
setserial -g /dev/ttyS*
```

**用途**：查看传统串口的 I/O 地址、中断号等信息。若系统没有 `setserial`，需要先安装。

### 查看串口参数

```bash
stty -F /dev/ttyS0 -a
```

**用途**：查看指定串口当前的波特率、数据位、校验位、停止位等参数。USB 串口可把设备名换成 `/dev/ttyUSB0`。

## 常用日志和辅助命令

### 实时查看内核日志

```bash
dmesg -w
```

**用途**：插拔 USB 设备、采集卡、串口线时实时观察系统日志。

### 查看最近硬件相关日志

```bash
dmesg | tail -n 100
```

**用途**：查看最近的内核日志，适合刚插入设备后快速确认系统反应。

### 查看设备权限

```bash
ls -l /dev/video* /dev/ttyUSB* /dev/ttyS* 2>/dev/null
```

**用途**：查看视频节点和串口节点的所属用户、用户组和权限。常见需要加入 `video`、`dialout` 等用户组。

### 查看当前用户所属用户组

```bash
groups
```

**用途**：确认当前用户是否在 `video`、`dialout` 等设备访问相关用户组内。
